Now its time to secure a domain name for our website.
Consider the name you would like to use for your site and search for it using a DNS (domain name system) registrar like: Porkbun, Hover, iwantmyname. (I will be using porkbun.com for demonstration). Depending on the TLD (“top-level domain” or domain ending — .com, .net, .org, etc), most domain names are fairly cheap and usually only ask for a yearly fee. Because were using github pages to host our websites we dont need to pay for monthly hosting fees and server space, which is normally the case.
